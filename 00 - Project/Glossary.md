# Glossary

## Emerson Workbench

The department-level operational LMS described in the [[Project Charter]]. The
single home for all Emerson Educational Services course content and primary
source materials.

## Bench Notes

The **instructor guide** for a course or module. Contains teaching sequence,
talking points, timing, demo setup, common questions, and answer keys. Generated
from shared source content alongside the [[Glossary#Bench Book|Bench Book]] so
the two never drift.

## Bench Book

The **student guide** for a course or module. Contains the same underlying
material as the Bench Notes, framed for the learner — no answer keys, no
instructor timing.

## Source content

Authoritative Markdown that describes a concept, procedure, or component once.
Course modules reference source content rather than copying it, so an edit to the
source updates every place it appears.

## Source Library

The repository of primary source materials hosted in the Workbench — the
[[Emerson Control Valve Handbook]], [[Industry Handbooks]], and
[[Technical Publications]]. See [[Source Library]].

## Class / Course

A deliverable unit an instructor opens and teaches from, e.g.
[[1400 — Course Home|1400 Valve Trim and Body Maintenance]]. Composed of modules.

## Presentation artifact

The rendered, presentable output of a course — for Stage 1, an HTML presentation
that preserves the look and feel of the original PowerPoint deck.

## 4–20 mA

The standard analog instrumentation current-loop signal. Stage 3 explores
sending these signals from the Workbench to classroom hardware.

## Loop calibrator

A handheld instrument that can source and measure loop signals (mA, voltage,
pressure). Stage 3 explores using one to help control a valve during
diagnostics demonstrations.
