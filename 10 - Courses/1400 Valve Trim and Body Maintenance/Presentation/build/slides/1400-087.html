3. Fisher™ Sliding Stem Spring and Diaphragm Actuator Maintenance

After completing this module the student will be able to:

  1. Define the action of the actuator
  2. Identify Fisher™ Spring and Diaphragm Actuator types
  3. Identify the fail mode of the control valve assembly
  4. List valve forces that affect actuator operation/selection
  5. Define Bench Set and describe the procedure for setting bench set
  6. Describe common maintenance procedures for Fisher 657 and 667 Actuators
  7. Describe Deadband as it applies to control valves
