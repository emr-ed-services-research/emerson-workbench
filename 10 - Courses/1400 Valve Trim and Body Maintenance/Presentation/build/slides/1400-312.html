Operational Block Diagram

  • Controller compares process measurement to set point
  • Process PID applied to correct error
  • Control signal = Remote Set Point (RSP) sent to DVC
  • Responds with change in drive signal
  • Initial response determined by proportional gain
  • Minor loop feedback (MLFB) provides feedback from relay response to printed wiring board (PWB)
  • Travel position and Travel Velocity Gain sent to PWB from travel sensor
  • Integrator eliminates error
  • Responds when actual travel outside of user defined range – default .25%
