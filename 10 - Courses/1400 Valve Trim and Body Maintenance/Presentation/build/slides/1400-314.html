Diagnostic Tiering

  • Identifies operation and diagnostic capabilities of device
  • HC = HART® Communicating – features such as alert capabilities, stroke valve test, and status monitor
  • AD = Advanced Diagnostics – Offline diagnostics using ValveLink™ Software – Step response and Dynamic Scan
  • PD = Performance Diagnostics – Online diagnostics using ValveLink Software – PD One Button, Friction, Profiles
  • ODV = Optimized Digital Valve – Advanced tuning features for special applications
