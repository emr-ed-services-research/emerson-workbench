Exercise 2 – Connect to Device with ValveLink Mobile

  • Follow the steps below to connect to a FIELDVUE digital valve controller using an Emerson Communicator (475 or AMS Trex) and ValveLink Mobile.
  • Ensure leads from the Communicator are connected as indicated in the previous exercise
  • Turn on the current source and set signal to at least 4mA to power the device
  • Power on the Communicator and then select ValveLink Mobile
  • Indicate the Communication Protocol for the device
  • For this Exercise we are connecting to a HART device
  • To finish connection Select connect in the upper left-hand corner of the screen
  • We will need to make changes to the device configuration so DO NOT select “Read Only”
  • Select “Connect”
  • You will see information change on the communicator screen as it connects to the device
  • Connection can be confirmed when “Connect Task Complete” is shown and highlighted green
  • Select done to return to ValveLink Mobile main menu
