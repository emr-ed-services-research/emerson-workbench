Changing Instrument Mode

  • Select the instrument mode button in bottom right of screen in main menu
  • Instrument mode screen opens indicating current mode
  • Change by selecting box by other instrument mode and select “Apply”
  • Program begins to scan device and prepare to adjust to control signal
  • Valve may move when set to In Service as device responds to applied control signal
  • “Instrument mode written” indicates mode change is complete
  • Select done to return to main menu
