Instrument Mode During Calibration

  • Valve strokes during calibration procedures
  • Ensure valve is properly blocked and isolated from process if installed in process line
  • Set device to “Out of Service” to run calibration procedures
  • Device will respond to commands from communicator and ValveLink program
  • Device will not respond to changes in control signal from control system
  • Start button will show in lower right corner of screen if device already set to out of service
