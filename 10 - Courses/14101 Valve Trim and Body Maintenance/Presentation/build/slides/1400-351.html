Connection Process

  • Connect menu allows user to select:
  • Read only – allows user to see device parameters but not make changes
  • COM1 / Analog or Multidrop –
  • Analog - ValveLink Mobile will only look for devices at polling address 0, this is the most common as most systems are set up for point-to-point communication (Default setting)
  • Multidrop – ValveLink Mobile will connect to device at selected address on multidrop segment – Addresses can be selected from 0 to 15
  • Select Connect button to start connection process
  • Connection process opens COM port and scans for device
  • Once device is found ValveLink Mobile continues to scan device to collect device information
  • Firmware
  • Hardware
  • HART Revision
  • Device ID
  • HART Tag
  • Select done when connection task complete is indicated
