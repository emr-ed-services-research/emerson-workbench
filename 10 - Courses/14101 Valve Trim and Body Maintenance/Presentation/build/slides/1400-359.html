Initial Setup using ValveLink™ Mobile

  • Device configuration can be done by selecting the Setup menu icon from the main Menu
  • Set up menu includes:
  • Setup Wizard – used for initial installation and configuration
  • Detailed Setup – set extended operation and alert parameters
  • Engineering Units – used to reference pressure readings, surface areas, etc.
  • Write Protection – add and remove protection of calibration and configuration of device
  • Save Detailed Setup – saves device configuration to 475 Field Communicator
  • Spec Sheet – view and edit spec sheet information stored on device
  • Perform Setup Wizard
  • Sets Critical information needed for device operation
  • Can be ran with or without the device mounted on the valve
  • Typically, only needs to be ran on the first installation of the FIELDVUE™ digital valve controller
  • Select the Setup Wizard icon from the menu to begin
