Mounting Information – Relay Type

  • List of relays used for FIELDVUE digital valve controller operation
  • Helps identify device operation
  • Single Acting (A, B, or C relays)
  • Double Acting (A relays Only)
  • Indicates what pressure sensor(s) device should monitor for operation and diagnostics
  • Special App = Special Application
  • Same relay construction as standard applications
  • Allows single acting device to use unused pressure sensor
  • Allows for solenoid integrity testing (SIS tier)
  • Lo-Bleed Relays
  • Relay construction changed – output bleed ports blocked
  • Reduces air consumption
