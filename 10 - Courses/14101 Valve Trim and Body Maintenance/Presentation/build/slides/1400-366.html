Exercise 1 – Setup Wizard

  • Follow the steps below to configure the FIELDVUE Digital Valve Controller using the Setup Wizard.
  • Ensure you are connected to the device
  • Apply at least 12mA signal to DVC to ensure it is properly powered during procedure
  • Select the Setup Icon to see the Setup Menu
  • Select Setup Wizard to begin
  • Use the > button to display parameters lists or enter parameter information for a given field
  • Enter the actuator information – Required information for a Fisher Valve and Actuator should be listed on the nameplates (complete all fields)
  • Mounting Information - Relay Type – remove front cover of DVC and enter correct information for installed relay
  • Factory Settings
  • For this exercise assume this is the first time the device is being mounted and configured
  • Factory Defaults are automatically applied during Setup Wizard with ValveLink Mobile
  • With all the appropriate fields completed select “Apply” to write information to the device
  • Stop at this point before proceeding with the auto travel calibration.
  • Inform instructor when exercise is complete
