Travel Calibration Using ValveLink™ Mobile

  • Two calibration methods
  • Auto Travel Calibration
  • Most commonly used
  • Device automatically finds end points
  • Requires two mechanical stops
  • Manual Travel Calibration
  • User defines end points
  • Often used with large / long stroke assemblies
  • Used in application without mechanical stop(s)
  • Select calibration icon from main menu
  • Select calibration method
