Optional Exercise – Manual Travel Calibration

  • Follow the steps below to calibrate the travel for the FIELDVUE digital valve controller and valve assembly.
  • Ensure the Setup Wizard has been completed for the first installation of the DVC
  • Place the device “Out of Service”
  • Select Manual Travel from the Calibration menu
  • Use communicator and ValveLink Mobile to manually position the valve at 50% travel and select next
  • Use communicator and ValveLink Mobile to manually position valve at desired end points (use travel scale for reference) select next after each end point is made
  • ValveLink mobile will write the travel settings to the valve
  • Pressure control is not calibrated with the Manual Travel Calibration in ValveLink Mobile
  • Select Done and put the assembly “In Service”
  • Use current source to move valve, and indicate corresponding travel positions:
