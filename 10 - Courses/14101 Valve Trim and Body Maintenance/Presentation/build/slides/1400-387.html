Optional Exercise – Relay Adjustment (Piston Only)

  • Follow the steps below to configure relay A for double acting actuators. ValveLink Mobile does include an independent calibration function of the Relay. This calibration function is included with the Auto Travel Calibration. Best practice is to use Auto Travel calibration when replacement or adjustment is needed.
  • An independent relay adjustment procedure is available using the HART DD with the field communicator. The procedure below outlines the steps required for this adjustment.
  • Connect to device and start up communicator
  • Select HART (475) or Field Communicator (Trex) to begin communication with the device
  • Ensure at least 12mA is applied to properly power device and supply pressure is set during procedure
  • The device should be set to “Out of Service” – Use the following menu selections:
  • Configure > Manual Setup > Mode and Protection > Change Instrument Mode
  • Follow the menu selections below:
  • Configure > Calibration > Relay Adjust
  • Control valve assembly should move away from travel stops
  • If the valve is contacting a travel stop the relay adjustment procedure cannot be performed
  • Try to run travel calibration to establish calibration end points and perform Relay adjustment procedure again
  • Adjust star wheel as indicated by program and monitor relay position percentage shown on screen
  • You have a 15 second window to try and make an adjustment, if you run out of time it will ask if you need more time select “Yes”
  • Carefully make minor adjustments to star wheel
  • When percentage value begins to change, stop adjustment until value stabilizes
  • Make additional adjustments as needed
  • When all adjustments are made wait for time to run out and select “No” to indicate not additional adjustment time is needed
  • When finished with Relay Adjustment run appropriate travel calibration procedure as needed.
  • Set device to “In Service” when complete
