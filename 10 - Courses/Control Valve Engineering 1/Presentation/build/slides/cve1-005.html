Case A: Service Conditions and Preliminary Cv

  • 1Cooling-water bypass line: P1 = 150 psig, P2 = 100 psig, so ΔP = P1 − P2 = 50 psi
  • 2Q = 200 gpm of water (SG = 1.0), 70°F, ANSI Class 300, Class II shutoff
  • 3Preliminary Cv = Q × √(SG / ΔP) = 200 × √(1.0/50) = 200 × 0.141 ≈ 28
