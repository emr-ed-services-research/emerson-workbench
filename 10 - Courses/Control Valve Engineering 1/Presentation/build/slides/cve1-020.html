Check Your Knowledge: Sizing for Real Shutoff

A service specifies Class V metal-seat shutoff. The actuator has been sized to the calculated stroking thrust only. Per Figure 5.3, what is the real risk?

  • A.  None — stroking thrust and seat load are the same requirement
  • B.  The actuator likely can't generate the seat load Class V requires — five to ten times a lower class's demand
  • C.  The risk is packing friction, not seat load
  • D.  Class V only matters for rotary valves, not this globe valve

B · Total actuator force = A + B + C + D. Stroking thrust covers part of A. Class V's seat load (B) can run 700-1000+ lbf per lineal inch — checking it is a separate step Figure 5.3 exists for.
