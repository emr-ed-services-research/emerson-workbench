The Valve Selection Process

  1. Determine service conditions — P1, ΔP, Q, T1, fluid properties, allowable noise, ANSI pressure class
  2. Calculate a preliminary Cv — check the noise and cavitation levels it implies
  3. Select trim type — standard, noise-reduction, or cavitation-reduction, from step 2's result
  4. Select the valve body and trim size for the required Cv — this is where the rotary subtype gets chosen, noting travel, trim group, and shutoff option
  5. Select trim materials — compatible with the application and available in that trim group
  6. Settle remaining options — packing, additional shutoff hardware
