Check Your Knowledge — Leakage Classification & Fugitive-Emissions Standards

A vendor's quote for an occasional-cycling bypass isolation valve claims "FCI 70-2 Class VI shutoff" and, separately, "ISO 15848-1 Class AH stem-seal tightness" — using an ordinary packing gland, not a bellows design. The service doesn't require near-zero atmospheric leakage. Which claim is the one worth challenging before you accept the quote?

  • A.  The Class VI shutoff claim, because Class VI is always overkill for an isolation valve
  • B.  The Class AH tightness claim, because Class A is realistically achievable only with a bellows design
  • C.  Neither claim — a service that doesn't need near-zero leakage doesn't need an ISO 15848-1 rating at all
  • D.  The mechanical-cycle count, because an isolation valve should be qualified to a control-valve CC class, not a CO class

B · Challenge the Class AH claim (no bellows)
