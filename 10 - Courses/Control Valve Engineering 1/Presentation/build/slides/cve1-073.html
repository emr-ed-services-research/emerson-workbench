Class 300 — Adequate at This Temperature, at This Site?

A body/bonnet nameplate reads Class 300 — is that adequate for this service, at this temperature, on this installation? A pressure class isn't a fixed rating: the same Class 300 body holds less pressure as service temperature climbs. And even a body/bonnet whose class genuinely fits the service can still fail an inspection if it sits somewhere a different code governs. Verifying the class and identifying the jurisdiction are two separate checks — skip either one, and a mechanically sound valve becomes a rejected shipment.
