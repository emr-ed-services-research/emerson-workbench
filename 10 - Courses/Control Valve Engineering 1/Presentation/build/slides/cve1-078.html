Where Each Standard Stands Relative to B16.34

StandardWhat it coversStatus for control valves
ANSI B16.5 — flange / flanged-fitting designWas itself a valve design standard before 1973 (butt-weld end) & 1977 (flanged end)Design responsibility transferred to B16.34; now mainly a dimensional/rating reference (“mates with ANSI XXX flanges”) — older specs may still cite it as the design basis
MSS SP-66 — valve design standard, pre-B16.34“Special inspections” concept for raising pressure-temperature ratingsGenerally superseded by B16.34 conformance; replaced by B16.34's own special-class ratings
MSS SP-67 — butterfly-valve design & test performance, its own Type I/II/III leak classesButterfly-valve design & test performanceLeak classes superseded in most control-valve usage by ANSI/FCI 70-2; source directs control valves to ISA S75.19 & ANSI/FCI 70-2 instead (its own seat-leak test can't distinguish leak-rate across trim styles/sizes); still supplies face-to-face dimensions for certain butterfly valves
ANSI B16.10Face-to-face dimensions (gate/plug/check/ball/control valves, named size & class bounds)Current & unsuperseded
ANSI B16.37Hydrostatic testing at 1.5× cold working pressure per B16.34Current; Fisher adds a post-assembly aerostatic test beyond the bare code requirement
MSS SP-53/54/55 — magnetic-particle / radiographic / visual casting examinationCasting examination methodsEffectively superseded — B16.34 or ASTM E94-equivalent methods recommended instead for broader acceptance
MSS SP-61Pressure testing of steel valves generallyNot superseded, but out of scope here — explicitly not intended for control valves; its seat-closure tests are written for shutoff/isolation/on-off/block valves
