Tracing Jurisdiction for a Real Installation

1

Locate the boundary

Case: a steam-drum level control valve. It isn't welded straight to the drum with no intervening joint — it sits on the piping running off the drum, past the first circumferential weld end, flange face, or threaded joint, so the termination-point rule places it in boiler external piping, not boiler proper.

2

Cross-reference the standards

On boiler external piping, ASME BPVC governs administratively while ANSI/ASME B31.1 governs technically — inspection records, data reports, and stamping are required unless a documented BPVC Section I waiver applies. Then check whichever supporting standard is cited for the valve itself (B16.34, B16.10, B16.37, or an older MSS SP) against the crosswalk just taught — an older spec can still name a standard B16.34 has since superseded.

Getting the code jurisdiction right while still citing a superseded standard for the supporting requirement is only half the cross-reference done.
