Adjusting Bench Set

  1. Seat the valve fullyThe reference point that demands the greatest accuracy of any setting in the whole sequence.
  2. Turn the spring adjuster to the bench set's lower valueFor an air-to-open actuator this is the pressure at which opening travel begins; for air-to-close, where closing travel begins. This sets the correct initial spring compression.
  3. Confirm against the seating-force relationshipSeating force = applied pressure − bench set − spring compression already used by travel. Check the setting against this relationship (see the previous slide's graph).
  4. Expect some real spring variationReal springs carry manufacturing tolerance in spring angle — expect and check for some variation rather than assuming a fresh spring matches the nameplate exactly.

Grounded directly in Control Valve Handbook, 6th ed., §8.5.5 (p.186) — the spring-adjuster step, the seating-force equation, and the spring-tolerance note are stated there almost verbatim; no figure placed here. Component Index: cvh-topic-bench-set-adjustment.
