A Compliance Gap, Not a Documentation Gap

US fugitive-emissions regulation (LDAR — Leak Detection and Repair) requires periodically monitoring every valve in regulated service against a 500 ppmv leak threshold — 100 ppmv in some cities — because non-point-source VOC leaks with no single point to inspect add up to an estimated 400 million lb/year nationally. Module 1 selected a packing system against a pressure/temperature and emissions-class envelope; that selection is not itself the compliance record. A packing system that can’t be verified against a real, ongoing measurement-frequency requirement is a compliance gap, not a documentation gap — this module is that verification step.
