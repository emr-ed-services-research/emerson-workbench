Bonnet Choice Can Defeat the Packing Spec

A bonnet is not just a mounting point for the actuator — it’s a pressure-retaining component that also decides how far the packing box sits from process temperature, and how much stem leakage the service can tolerate. Get bonnet type wrong for a temperature extreme or an isolation requirement and it defeats a correctly-selected packing system outright: packing rated to 232°C accomplishes nothing if the bonnet lets the packing box itself run hotter than that.
