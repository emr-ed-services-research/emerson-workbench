Working the Propane Case — First Assumption (NPS 3)

NPS 8 propane line, ASME CL300 globe valve with equal-percentage cage.
  1. Given: q = 800 gpm, P1 = 314.7 psia, P2 = 289.7 psia (ΔP = 25 psi), Gf = 0.50
  2. First assumption: NPS 3 valve, rated Cv = 121
  3. Between identical concentric reducers: ΣK = 1.5·(1−9/64)² = 1.11 → Fp = 0.90
  4. Solve: Cv = q ÷ (N1·Fp·√(ΔP/Gf)) = 125.7
Common failure125.7 exceeds the NPS 3 valve’s own rated Cv of 121 — the assumption doesn’t hold. Skipping the rating check (or forgetting Fp entirely, which would have understated the required Cv even further) is how an undersized valve gets specified: the arithmetic looks clean right up until it’s compared against the candidate’s real capacity.
Try it yourself before turning the page: step up to NPS 4 (rated Cv = 203) and run the same ΣK → Fp → Cv sequence. Slide 147 walks the identical numbers — check your result against it.
