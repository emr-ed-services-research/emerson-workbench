Working the Propane Case — Converging on NPS 4

  1. Reassume NPS 4, rated Cv = 203
  2. Recompute for the wider bore: ΣK = 0.84 → Fp = 0.93
  3. Required Cv = 121.7 — safely under the NPS 4’s rated 203
  4. Refine: feed 121.7 back into the Fp equation → Fp = 0.97 → Cv converges to 116.2, close enough to 121.7 to stop
Common failureTreating the first passing Cv as final. 121.7 sits far enough from the 203 used to derive that Fp that one more iteration is worth running — stopping at the first Cv under the rated capacity, without checking whether the Cv/d² ratio the Fp calculation was built on still holds, is how a “passing” calculation still ships a size that’s subtly off.
Try it yourself: this refinement moved the answer from 121.7 to 116.2 — about 5%. Would you have stopped there, or run one more iteration? There’s no fixed rule; make the call, then see whether you agree with the source’s own choice to stop at NPS 4, roughly 75% open.
