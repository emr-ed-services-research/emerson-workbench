Checking the Steam Case for Choked Flow

Same Design ED case as slide 155.
  1. xT = 0.688 (rated, 4-in valve at 100% travel), Ki = 0.5·(1−(4/6)²)² + [1−(4/6)⁴] = 0.96, Fp = 0.95 (slide 155), N5 = 1000, Cv = 236 (assumed valve’s rated capacity)
  2. xTP = (0.688/0.95²)·[1 + (0.688·0.96/1000)·(236/16)²]−1 ≈ 0.67 — well below the 0.688 the flow-coefficient table alone would suggest
  3. Fk = k/1.4 = 1.28/1.40 = 0.91, so Fk·xTP = 0.61
  4. Against the actual x = 0.49: NOT choked (0.49 < 0.61), so Y = 1 − 0.49/(3·0.91·0.67) = 0.73 — the value slide 155’s Cv calculation already used
Common failureUsing the flow-coefficient table’s rated xT (0.688) directly instead of correcting it to xTP for this valve’s reducer geometry. The uncorrected number gives Fk·xT = 0.626 against Fk·xTP = 0.61 — both still clear the actual x = 0.49 in this case, but the margin to choked flow is narrower than the uncorrected number suggests, and on a service closer to the edge, skipping the fittings correction can flip the pass/fail call outright.
Try it yourself: with Fk·xTP = 0.61 against the actual x = 0.49, how much margin sits between this case and choked flow — and does that margin feel comfortable, or close enough to the edge that you’d flag it for a second look on a real job?
