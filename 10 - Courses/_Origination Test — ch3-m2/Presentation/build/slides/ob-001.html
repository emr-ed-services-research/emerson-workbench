Bench Set — the Pressure Range for Rated Travel

  • Bench-set line — 0 % to full rated travel
  • Bench-set range

Bench set is the spring compression that makes the actuator stroke its full rated travel over the nameplate pressure range — defined with no packing friction, so it is set with the actuator off the valve.
