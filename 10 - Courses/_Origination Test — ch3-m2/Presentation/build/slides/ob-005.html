Where Bench Set Fits in the Mounting Sequence

  1. Set the actuator on the bonnet and run the yoke locknut down — actuator secure, valve and actuator stems not yet connected.
  2. Verify the bench set now, with the stems unconnected, so packing friction is out of the picture.
  3. Install the two-piece stem connector — engage each stem by at least one stem diameter of thread.
  4. Stroke the assembled valve full travel and recheck it against the nameplate rated travel.
