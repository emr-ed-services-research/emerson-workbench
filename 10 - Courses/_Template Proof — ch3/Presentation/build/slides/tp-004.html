Read the Nameplate First

  • 1TYPE / SIZE — which actuator this is
  • 2BENCH SET — the pressure range for rated travel
  • 3TRAVEL — the rated stroke to verify against
  • 4MAX STEM DIA — the largest valve stem this actuator fits

After Fisher 657 Instruction Manual (D100306X012), Table 1 (Specifications) / nameplate layout. Example values — a real actuator's will differ. The four keyed fields are the ones ch3-cmp-nameplate names as defining a correct bench set. Component Index: ch3-cmp-nameplate.
