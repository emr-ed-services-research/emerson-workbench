sweep for `Figure 2.` across every page in range, plus rendering and
reading all 13 pages) — Chapter 2 is company/sales/product-portfolio
content (manufacturing, lab testing, service network, then a run of named
Fisher/Baumann/FIELDVUE product photos grouped by application), not
engineering-figure content.

**Judgment call, flagged per this pass's own instructions:** most of this
chapter is marketing copy that teaches nothing a course would cite (generic
photos of a technician using a micrometer, a factory-floor photo, a flow
lab photo, six generic "testing capability" panels with no named product,
and an "Other Resources"/company-history spread) — these are **not**
catalogued; there is no teaching content to lose. The chapter's four named
product-portfolio sections (Sliding-Stem Control Valves, Rotary Control
Valves, Field Instruments and Valve Accessories, Severe Service Solutions),
however, present 33 separately-headed, separately-captioned panels, each
naming a real Fisher/Baumann/FIELDVUE product tied to a specific refinery
application or service condition — genuine valve/instrument-*selection*
teaching content (which product answers which service need), the same
subject Chapter 3 covers structurally and Chapter 4 covers by process unit.
None of these panels carry a printed figure number. Per the "unnumbered-
but-real diagrams" edge case (the figures-only rule excludes tables, not
real teaching content that happens to lack a number) and the "own bold
heading = separate record" bundling precedent (each panel is independently
headed and captioned, not one continuous reference table), all 33 are
catalogued individually below, using a synthetic locator. This is a real
editorial call, not a mechanical one — see Open Items.
