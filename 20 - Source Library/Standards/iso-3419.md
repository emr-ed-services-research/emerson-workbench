## Why it is registered

**It is the ISO counterpart to `ASME B16.9`** — the same subject, butt-welding
fittings, from the other standards family. It was found while looking for
something else entirely (irrigation standards, which Emerson does not hold),
and it is registered now because the component catalogue needs to be able to
say *which* family a fitting's dimensions came from. A catalogue that can only
answer in ASME has an unstated assumption in it.

Worth opening when the catalogue first needs a metric-sourced fitting, or when
a course teaches an installation outside North America.
