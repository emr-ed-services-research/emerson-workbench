# Vitruvius — Archive Use Log

See `Vitruvius.md` for what this is. Every entry below is one Historic
Educational Services Training Content item Vitruvius has actually reviewed
and verified for use in a course — not a cataloguing pass over the
archive. The archive itself stays outside the Component Index; this log is
the only record of which pieces of it have ever been vetted.

**Entry shape:**

```yaml
id: vit-archive-<slug>
archiveSource: >
  Which D750xxx module and which specific page/figure/case.
usedFor: >
  What it was used for (e.g. a consequence-reveal case in a specific
  course/module).
currencyCheck: >
  What was checked against a current source before use, and the result —
  including if the archive content turned out to be superseded and was
  rejected rather than used (that's a real, useful outcome to log, not
  just a silent skip).
verifiedDate: YYYY-MM-DD
```
