# 30 - Templates

Obsidian note templates. **Not code** — these are the starting points for new
vault notes, nothing here is built or run.

| Template | For |
| --- | --- |
| `Course Home.md` | A new course's home note |
| `Source Document.md` | A new entry in the Source Library |
| `Bench Notes Module.md` | A Bench Notes module |
| `Bench Book Module.md` | A Bench Book module |

The course *runtime* templates — the actual slide layouts — are not here. They
live in `40 - Engine`.
