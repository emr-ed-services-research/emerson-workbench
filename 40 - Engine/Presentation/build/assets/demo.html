Emerson Workbench — ISA Schematic Symbol Library: Composed Example

Phase 1 asset build. This is a standalone proof composition, not a course slide — horizontal (flow left–to–right), built entirely from the primitives defined in symbol-library.svg. It demonstrates a basic tank level-control loop: a level transmitter (LT) senses the tank's level and signals a panel-mounted level controller (LC), which signals the control valve's actuator to throttle outlet flow — the same functional skeleton as the vault's own Control Valve Handbook Fig. 1.1 feedback loop (already used on cve1-005.html), but drawn as a real physical piping/instrumentation schematic instead of an abstract block diagram.

Process / piping line (solid, 4px, charcoal)
Instrument signal line (dashed, 2px, grey)

Reading the loop: the tank's level is sensed by LT (a field-mounted instrument — plain circle), which sends a signal to LC (a panel/DCS-mounted controller — circle bisected by a line), which signals the control valve's diaphragm actuator to throttle the outlet line. Solid heavy lines are physical process piping; dashed lines are instrument signals — never the two drawn the same way. See reference.md for full per-symbol sourcing.
