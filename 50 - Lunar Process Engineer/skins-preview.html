TWO SKINS, ONE RIG

Bio-Grow Bay 3. The same netlist, the same dynamics, the same scenario — rendered twice. Nothing below chrome knows which of these it is being drawn as, and the hand wheels below drive both at once.

Both panels are painted from one LPE.net() declaration through one LPE.dyn() solve. The left one passes the game’s skin to piping().draw(g, skin) and schem.draw(g, plan, theme); the right one passes the core’s skins/modern.js. The core itself names no colour — it names the roles line, symbol, fill, label, ground, gap and the skin answers them, which the layer guard enforces on every build.
