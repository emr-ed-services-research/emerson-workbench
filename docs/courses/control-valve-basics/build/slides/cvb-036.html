Field-Reversible and Rotary Diaphragm Actuators

  1. 1Field-reversible multi-spring actuator — can be assembled for either direct- or reverse-acting in the field, without a different casting
  2. 2Diaphragm actuator for a rotary valve — the same spring-and-diaphragm principle, converted to rotation through a lever on the valve shaft
