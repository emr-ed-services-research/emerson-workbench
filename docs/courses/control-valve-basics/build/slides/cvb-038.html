Manual, Electric, and Rack-and-Pinion Actuators

  1. 1Manual actuator — sliding-stem — a handwheel gives manual override with no pneumatic supply; often actuates the bypass valve around a control valve
  2. 2Manual actuator — rotary — the same handwheel-override principle, built for a rotary valve
  3. 3Electric actuator — sliding-stem — an electric motor with gear reduction replaces pneumatic supply, for sites with no instrument air
  4. 4Electric actuator — rotary — the same motor-driven principle, built for a rotary valve
  5. 5Rack-and-pinion actuator — a compact, economical pneumatic option for rotary valves; backlash limits it to on/off service, not precision continuous throttling
