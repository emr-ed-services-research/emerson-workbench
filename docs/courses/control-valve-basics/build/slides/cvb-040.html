How a Pneumatic Positioner Works

  1. 1Beam and feedback axis compare actual stem position (fed back through the cam) to the incoming command signal
  2. 2The flapper moves closer to or farther from the nozzle, changing nozzle back-pressure
  3. 3The relay amplifies that change into the diaphragm output pressure that drives the actuator — stopping only when actual position matches command
