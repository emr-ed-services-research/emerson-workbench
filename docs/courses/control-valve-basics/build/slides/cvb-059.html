Check Your Knowledge: Why Performance Varies

A tech logs a complaint: "the loop hunts right around 70% open, but it's rock-solid everywhere else in the travel." You pull this valve's installed-gain curve and find it drops off sharply right around 65–75% travel; the on-file response-time data for this exact configuration is normal, nothing unusual. Is this a deadband problem?

  • A.  No — deadband would show up as sluggishness across the whole travel range, not one narrow band; this is the installed gain changing sharply right there, which the tuning can't fully compensate for at every point
  • B.  Yes — hunting anywhere in the loop always means deadband; check the packing first
  • C.  No — this is purely a response-time problem; swap in a faster positioner
  • D.  Yes — the test loop itself is generating the variability, not the valve

A · Installed-gain change, not deadband
